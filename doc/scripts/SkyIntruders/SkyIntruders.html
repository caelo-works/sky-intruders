1 Description

[hide]

Version française de cette documentation

Sky Intruders works in two modes, one per tab of its dialog. Everything runsinside PixInsight: there is no native helper to install.

  • Night trails scans the light frames of one night. The frames areregistered internally and trails are detected on the registered differenceimage, so nebulosity is not mistaken for a trail. Every trail is cross-matchedagainst orbital elements propagated with SGP4, so that an identified trailcarries the name of the satellite. Unmatched trails are tested against theactive meteor showers, and slow, coherent movers become asteroid candidates.The result is an annotated composite image and a night log with a ready-to-postforum text.
  • Treasure Hunt takes one plate-solved image and queries deep catalogsfor the galaxies, quasars, planetary nebulae and asteroids inside the field.Every catalog position is then measured on the image, so the report separatesthe objects actually captured from those in the field but below the noise ofthe image. The result is a star chart, opened as a new image window, and anillustrated HTML report.

Both modes download catalog data over HTTPS; seeNetwork connections for every host contacted and what issent to it, and Files written on your computer for everythingthe script stores.

2 Usage

[hide]

The script is available from the Script > CaeloWorks > Sky Intrudersmenu item. It requires PixInsight 1.9.4 or newer, on Windows, macOS and Linux.

2.1 Input list

The Input list is shared by both modes. Add files… accepts.fits, .fit, .fts and .xisf files, Add folder…adds the frames of one folder (it does not recurse into subfolders), andClear empties the list. A file already in the list is not added twice.

In Night trails the list holds the light frames of one night, whichneed the DATE-OBS and EXPTIME keywords. The first frame of the list isthe registration reference and the source of the plate solution of the field:put a plate-solved frame first. Satellite identification also needs anobserver site, read from the SITELAT / SITELONG, OBSGEO-B /OBSGEO-L or LAT-OBS / LONG-OBS keywords, or entered by hand in thedialog. Without a site, trails are still detected but cannot be named, and thedialog says No observer site — satellites not identified.

In Treasure Hunt the list holds one plate-solved image. When the listis empty, the active image window is used. An image without an astrometricsolution is refused with a message.

The Language list switches the interface, the reports and the star chartbetween English and French. Every setting is remembered between sessions.The documentation button at the left of the Language list opens this page,in the interface language, in the PixInsight documentation browser.

3.2 What is never sent

Your observer site is never sent: satellite orbits are computed on yourcomputer. File names, image data and identifiers of any kind are never senteither. There is no telemetry and no usage tracking. Everything downloaded isdata, orbital elements and catalog rows; nothing downloaded is ever executed.

The script makes no automatic connection to the CaeloWorks website. Theby CaeloWorks label in the header of the dialog opens the product page,pixinsight-scripts.caelo.works , in your web browser only when you clickit (the French interface opens the French page).

3.3 Data integrity

  • Orbital elements , from every source: each element line carries amodulo-10 checksum, verified on download. An element set that fails isdropped, and the console says how many were dropped. A download in which morethan 5 % of the element sets fail is rejected as corrupt, and the nextsource, or the cache, is used instead.
  • CaeloWorks mirror : every file taken from the mirror is checkedagainst its SHA-256 manifest, tle/SHA256SUMS . After one retry, a filethat still does not match is not used; if the manifest cannot be fetched, nomirror file is used at all. CelesTrak or the cache is then used instead.
  • VizieR, SkyBoT and the CelesTrak SATCAT publish no checksums. Theyare protected by HTTPS and by strict format validation: an answer that is notgenuine catalog data, such as an error or maintenance page, is rejected,reported, and never cached.

4 Report attribution

[hide]

The checkbox Credit Sky Intruders at the end of reports sits under themode tabs and is shared by both modes. Its tooltip reads: Adds the line“Report generated by Sky Intruders for PixInsight” and the product pageaddress at the end of the night log, its forum text and the Treasure Hunt HTMLreport. Off by default: what you publish is up to you.

The option is saved in settings.json as reportAttribution . It isfalse by default, including for settings files written by older versions.When it is off, no attribution line is added to any report format.

The by CaeloWorks label in the header of the dialog is not affected bythis option. It stays in the dialog, and opens the product page only when youclick it.

5 External programs

[hide]

Sky Intruders starts no program of its own, and no executable is shipped withit. Only when you click Open image , Open HTML or theby CaeloWorks label, it asks your operating system to open the file orthe address with its default application. It runs cmd /c start onWindows, /usr/bin/open on macOS and xdg-open on Linux, with thefile path or the address as argument. Nothing is launched without an explicitclick from you.

6.1 The data folder

Everything persistent is stored in one folder of your home directory( %USERPROFILE% on Windows, ~ on macOS and Linux):.caeloworks/sky-intruders/ . Nothing is written inside the PixInsightinstallation.

To stop keeping night records, close the script, open settings.json in atext editor and set "saveHistory": false ; delete history.json if youwant the existing records gone too. The script rewrites settings.json whenits window closes, so edit it while the script is closed. To remove everythingthe script stores, delete the whole .caeloworks/sky-intruders folderwhile the script is closed.

6.2 The temporary folder

The script also writes to the system temporary folder, as reported byPixInsight:

  • si-night-reg-<token>/ , the registered frames of a Night trails run:removed at the end of every run. A leftover one means that PixInsight wasstopped during a run; it is safe to delete.
  • si-render-* , image encoding scratch files: removed right afteruse.
  • The copy of the Treasure Hunt HTML report written by Open HTML , andthe optional debug overlays si-frame-annotated-<token>-*.png : removedwhen the script window closes.
  • SkyIntruders-night-<date>-<token>.png , the annotated night image:kept on purpose, and not cleaned up automatically . It stays in thesystem temporary folder because it is the image the result window opens. Saveit elsewhere if you want to keep it; the copy in the temporary folder can bedeleted at any time.

Files you save yourself, with Save report… or Save HTML… , arewritten only where you choose.

7 Code signature

[hide]

The entry script of the package is signed with the CaeloWorks CertifiedPixInsight Developer identity; the signature is the SkyIntruders.xsgn fileinstalled next to it. The script therefore runs with the Allow executionof unsigned scripts option of PixInsight turned off. Modifying the installedfiles invalidates the signature.
